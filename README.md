# Cave Live Server

1. `npm install`
2. `npm start`
3. افتح: `http://localhost:3000/?u=اسم_حسابك_في_تيك_توك` واعمل مشهدك، وانسخ لينك المشهد في OBS (Browser Source).
4. للنشر العام: ارفع المجلد على Render / Railway / أي VPS (Node 18+). اللينك هيشتغل لأي حد.

- الشات والهدايا واللايكات وعدد المشاهدين بتيجي حقيقية من البث.
- مكان الإعلانات: في `index.html` ابحث عن `PUT AD CODE HERE` وحط كود الإعلان (AdSense وغيره) هناك.
- مكتبة `tiktok-live-connector` m رسمية،شوف README بتاعها.
- قسم المعرض وزرار + للمالك .
